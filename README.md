## 备注（易错点，供检查参考）

- **NC205911**：该题号在题单中的旧称是《随机序列》，牛客官方已将其题面更新为
  《牛牛的数学作业》（求极差与总体方差），本仓库按**当前题面**实现；
  方差使用整数公式计算后再除，避免浮点误差。
- **NC215089 默契**：相等时输出 `Tacit！`（**全角**感叹号），不相等时输出 `No Tacit!`
  （半角感叹号），与官方样例逐一对应。
- **NC20750 小飞机**：题目样例输出为图片，图案已与多篇 AC 题解逐字符比对确认；
  判题机忽略行尾空格。
- **NC15128 老子的全排列呢**：官方样例的输入/输出是玩笑占位符（`No_Input` /
  `Full arrangement of 1~8`），实际要求输出 1~8 的全排列（共 40320 行，字典序）。
- **NC22227 约瑟夫环**：人员编号为 **0 ~ n-1**（不是 1~n），输入为 `n k m`
  （k 为报数起始人编号，n ≤ 100）。
- **NC212226 回文数**：需用**全部**数码拼成最小回文数；回文数不允许前导 0，
  全 0 数码多于 1 个或左半部分无非零数码时无解输出 -1。
